## Recuperar un curso

Usar Download ZIP desde la etiqueta, o clonar con `git clone --branch ETIQUETA git@github.com:eseMike/respaldo-cursos-escritorio.git CARPETA_NUEVA`. Después crear una rama de trabajo. Las dependencias no se almacenaron; se reinstalan según cada proyecto.

No se fusionaron cursos entre sí ni se subieron credenciales. El historial original y metadatos locales se conservaron adicionalmente en la carpeta privada de respaldos del equipo.
